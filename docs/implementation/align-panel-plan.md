# Align パネル 実装計画

> **Status**: Planned — 2026-07-27 — 優先度低（ジオメトリ側の整列が先）

対象: 複数レイヤーを選択して整列・分布する UI。関連要件: REQ-UI-013、
REQ-UI-011、REQ-LAYER。

**関連**: `geometry-ops-plan.md`。あちらは**ジオメトリ内の要素**を手続き的に
整列するノードで、こちらは**レイヤーの Transform を書き換える** authoring 機能。
別々の機能なので混同しない。

## 問題

複数レイヤーを選んで「左揃え」「等間隔」ができない。数値入力で
`LayerTransform` の position を手で合わせるしかない。

土台は揃っている。

- レイヤー複数選択（#159）とその一括ドラッグ・一括編集（#161、
  1 undo ステップにまとまる）
- `LayerTransform` は各プロパティが独立した `AnimationChannel`
- Properties が `PropertiesTarget::Layers { comp_id, layer_ids }` を
  **選択順で**持つ

## 決定事項

### 対象は `LayerTransform` の position（x, y）

整列は position の書き換えとして実装する。スケールや回転は触らない。

### 基準は選択のバウンディングボックス、またはキーオブジェクト

- 既定: 選択レイヤー群のバウンディングボックス
- `PropertiesTarget::Layers.layer_ids` は選択順なので、
  **最後に選んだレイヤーをキーオブジェクト**にするモードを持てる
  （Illustrator の流儀）
- コンポジション基準（コンプの矩形に対して中央揃え等）も持つ

### バウンディングボックスの取得が難点

レイヤーの見た目の矩形は**そのレイヤーのネットワークを評価しないと
分からない**。Viewer は既に選択レイヤーのバウンディングボックスを
オーバーレイ表示しているはずなので（`done/tool-system-plan.md` の
選択ツール）、**その経路を再利用する**。

再利用できない場合は、position のみを基準にした整列（要素の大きさを
無視する）に限定し、その旨を UI で示す。**「大きさを考慮しているように
見えて実は position しか見ていない」状態を作らない。**

### アニメーション中のレイヤーの扱い

position がキーフレームで動いている場合、整列は「現在フレームの値」を
基準に「現在フレームにキーを打つ」のか「チャネル全体をオフセットする」のか
が曖昧。

**チャネル全体をオフセットする**を既定にする。整列は構図の操作であって
アニメーションの改変ではないため。キーフレームがある場合はその旨を
UI で示す。

### undo は 1 ステップ

#161 が確立した「レイヤー選択の一括編集を 1 undo ステップにする」形に従う。

## 実装単位

### 単位 1: 整列・分布の計算（`ravel-ui`、ヘッドレス）

- 整列 6 種（左 / 水平中央 / 右 / 上 / 垂直中央 / 下）。
- 分布 2 種（水平 / 垂直）× 2 モード（中心間等間隔 / 間隔等分）。
- 基準 3 種（選択バウンディングボックス / キーオブジェクト / コンプ）。
- 入力は「矩形の配列」、出力は「オフセットの配列」の純関数にする。

**完了条件**

- 各整列・分布モードの計算テスト（ヘッドレス、UI 不要）。
- 1 枚選択時に何も起きないテスト。
- 2 枚選択時の分布が no-op であるテスト。
- 幅が異なる要素の「間隔等分」が正しいテスト。

### 単位 2: パネルと配線

- `PanelKind::Align` を追加（`done/attribute-spreadsheet-plan.md` 単位 3 の
  登録先一覧と同じ手順）。
- レイヤー選択を読み、`LayerTransform` の position チャネルをオフセット。
- 1 undo ステップ。
- ロケール、アイコン。

**完了条件**

- 選択 3 枚を左揃えして position が期待値になるテスト。
- undo 1 回で全部戻るテスト。
- キーフレーム付きチャネルが全体オフセットされるテスト。
- 選択が空のときボタンが無効であるテスト。

### 単位 3: 文書更新

- `docs/specifications/ui-spec.md` にパネル追記。

## 非対象

- **ジオメトリ要素の整列**。`geometry-ops-plan.md`。
- **スケール / 回転の整列**。position のみ。
- **スマートガイド / スナップ**。Viewer 側の別機能。
- **整列のアニメーション**。1 回の編集操作。
- **パス / アンカーポイントの整列**。
