## 踏んだ罠（繰り返さない）

このセッションで実際に踏んで時間を失ったもの。

1. **`rg -rn` は `--replace=n`。** `grep` の癖で打つとマッチが全部 `n` に
   置換されて表示され、**存在しない API 名を読み取る**
   （`PopupMenuItem` を `nItem` だと思い込んだ）。行番号だけなら `-n` 単独
2. **`sccache` が直接 `cargo` 起動時だけ落ちる**
   （`Operation not permitted`）。`mise run check` と lefthook 経由は通る。
   原因未特定、回避は `RUSTC_WRAPPER=`
3. **rustfmt の整形差分で `git commit` が黙って落ちる。**
   終了コードを必ず見る。さらに**失敗したコミットはステージを残す**ので、
   次のコミットに無関係なファイルが混入する
4. **個票を `closed/` へ移すとリンクが切れる。** 件数だけ合わせても
   `docs:check` は通らない。他の文書からの参照を張り替える
5. **委譲中の worktree に呼び出し側が git 操作をしない。**
   検証のつもりで `git rebase` を走らせるとエージェントの足元でコミットが
   書き換わる
6. **変異検査の復元に `git checkout <file>` を使わない。**
   未コミットの修正本体ごと巻き戻る。コミット後に行うか、パッチを退避する

## レビューの効き方（このセッションの実測）

- **独立レビュー（codex）が 4 単位すべてで、実装者と自分が通していた欠陥を
  捕まえた。** ただし**提案された直し方をそのまま採ったのは 2 回だけ**で、

  変わるので却下）

  基準は「複数クレート / 複数パネル / サブシステムの作り直し」で、
  既存経路を消費するだけの変更は当たらない

  「ポート名リネームは残しキー移動だけ無効化」は、**エッジは直ったが

- **`HIGH-29` では独立レビューを追ううちに、gpui-component が
  `AppMenuBar` を持っていることが判明**して手書き 136 行が消えた。
  指摘そのものより、指摘を追う過程で見つかったものが大きかった
