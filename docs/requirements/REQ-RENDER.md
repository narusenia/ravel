# REQ-RENDER — レンダリング・エクスポート

## REQ-RENDER-001: キューベースバックグラウンドレンダリング

- **優先度**: Must
- **ステータス**: Draft
- **説明**: レンダージョブをキューに積み、バックグラウンドで順次処理。編集作業と並行可能。ジョブ管理UI（進捗、一時停止/再開、キャンセル、優先度変更）を提供。レンダリングはREQ-CORE-005の評価スレッドプール + デコードプールを使用。
- **受入条件**:
  - [ ] レンダージョブをキューに追加できる
  - [ ] バックグラウンドでレンダリングが実行される
  - [ ] レンダリング中も編集操作が可能
  - [ ] ジョブの進捗がUIに表示される
  - [ ] ジョブの一時停止/再開/キャンセルが可能
- **依存**: REQ-CORE-002, REQ-CORE-005

## REQ-RENDER-002: Write Nodeノード単位中間出力

- **優先度**: Should
- **ステータス**: Draft
- **説明**: 任意のノードの出力にWrite Nodeを接続し、中間ファイルとして書き出し可能。デバッグや素材生成に使用。Write Nodeもレンダーキュー（REQ-RENDER-001）で管理。出力フォーマットはFFmpeg経由で全コーデック対応。画像シーケンス（EXR/PNG/TIFF/DPX）出力もサポート。
- **受入条件**:
  - [ ] Write Nodeをノードグラフに追加できる
  - [ ] 任意ノードの出力をファイルに書き出せる
  - [ ] 出力フォーマット（コーデック/コンテナ）を選択できる
  - [ ] 画像シーケンスとして出力できる
  - [ ] レンダーキューで管理される
- **依存**: REQ-RENDER-001, REQ-MEDIA-001

## REQ-RENDER-003: OCIO + GPU LUTカラーマネジメント

- **優先度**: Must
- **ステータス**: Draft
- **説明**: OpenColorIO（OCIO）で色変換を統一管理。ACES/Rec.709/sRGB/Rec.2020等のカラースペース変換。`.ocio`設定ファイルをプロジェクトに読み込み可能。ビューア表示用にOCIO変換をGPU 3D LUTにベイクしwgpuシェーダで適用（リアルタイム性確保）。LUT再生成は設定変更時のみ。RustからはFFI経由。
- **受入条件**:
  - [ ] `.ocio`設定ファイルを読み込める
  - [ ] 入力/作業/表示カラースペースを設定できる
  - [ ] カラースペース変換が正確に動作する
  - [ ] ビューア表示にGPU LUTが適用される
  - [ ] ACES, Rec.709, sRGB, Rec.2020がサポートされる
- **依存**: REQ-GPU-001

## REQ-RENDER-004: モーションブラー

- **優先度**: Should
- **ステータス**: Draft（2026-07-27 新設）
- **説明**: レイヤー単位のモーションブラー。シャッター区間を N 分割して評価し積算する `Sampled` モードを基本とし、要素速度から方向性のあるにじみを作る `Velocity` モードを将来追加する。モードはユーザーが明示的に選ぶ（プレビューと書き出しでシステムが黙って方式を差し替えない）。サンプリングはレイヤーのネットワーク全体に及び、殻の Transform だけでなくネットワーク内部の時変要素（文字単位アニメーション等）もブレる。シャッター角度・位相は Composition 設定、有効化はレイヤー単位。実装計画は `docs/implementation/motion-blur-plan.md`。
- **前提**: アニメーションチャネルの連続時間評価（`KeyframeCurve::sample(f64)`）。現行は整数フレームのみで、サブフレーム評価してもキーフレーム駆動の要素がブレない。
- **受入条件**:
  - [ ] レイヤー単位で有効化でき、シャッター角度・位相が設定できる
  - [ ] 等速直線運動が期待範囲ににじむ
  - [ ] 回転がその方向にブレる
  - [ ] レイヤーネットワーク内部で動く要素（文字単位アニメーション等）がブレる
  - [ ] 時不変サブグラフがサンプル数ぶん再評価されない
  - [ ] プレビューと最終で品質段階（サンプル数）を分けられる
  - [ ] サンプル数 1 で無効時と一致する
- **依存**: REQ-CORE-002, REQ-CORE-006, REQ-CORE-007, REQ-CORE-009
