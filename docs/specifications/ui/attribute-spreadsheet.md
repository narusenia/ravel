# アトリビュートスプレッドシート

> 索引: [`../ui-spec.md`](../ui-spec.md)

選択ノードが評価したジオメトリの属性を、行×列で目視検査するパネルの
**意図した挙動**。実装状況の正は
[`../../ui-impl-status.md`](../../ui-impl-status.md)、設計の根拠は
[`../../implementation/done/attribute-spreadsheet-plan.md`](../../implementation/done/attribute-spreadsheet-plan.md)。

関連要件: REQ-CORE-010（ジオメトリ属性システム）、REQ-UI-013（パネル管理）。

## 原則

- **read-only。** 属性はノードグラフの計算結果なので、セルに書いても次の評価で
  消える。書き込みに意味を持たせるには下流への `attribute.set` 挿入のような
  意味付けが要るが、それは全要素ブロードキャストで 1 セル編集の意図と合わない。
  v1 は検査に徹する
- **第 2 の評価経路を作らない。** 表示対象は Properties と同じ
  `SelectedPropertiesTarget` の先頭ノードで、その結果は Viewer の評価要求に
  相乗りしたスコープターゲットとして届く。**画面に出ている絵と同じ評価の
  結果**を出す
- **行数に上限を切らない。** 仮想スクロール前提。1 万インスタンスでも
  「先頭 N 件」ではなく全件を持つ
- **動かないものを出さない。** ソートと列の並べ替えは実装しないので、
  その操作の見た目も出さない

## 画面

```text
┌ アトリビュートスプレッドシート ──────────────────────┐
│ ポイント 0  プリミティブ 0  インスタンス 25  ディテール 0 │ ← ドメインタブ + 要素数
├──────────────────────────────────────────────────────┤
│ # │ index │ P            │ rot   │ scale          │  ← 列 = アトリビュート
│ 0 │     0 │ (-40.0, -40.0)│ 0.000 │ (1.000, 1.000) │
│ 1 │     1 │ (-20.0, -40.0)│ 0.000 │ (1.000, 1.000) │
└──────────────────────────────────────────────────────┘
```

### ドメインタブ

- `Point` / `Primitive` / `Instance` / `Detail` の 4 つ。各タブに**そのドメインの
  要素数**を出す
- **0 要素のドメインのタブは押せない。** 切り替えても「要素がありません」しか
  出ないため
- プリミティブの件数はプリミティブそのものの数。属性列を持たないパスだけの
  ジオメトリで 0 と出てはならない

### 列

- 左端は**合成された要素番号列**（見出し `#`）。属性ではないので、`index`
  属性を持たないドメインでも必ず出る。横スクロールしても左に固定する
- 続けて**標準属性**（`index` / `id` / `P` / `N` / `Cd` / `alpha` / `pscale` /
  `rot` / `orient` / `scale` / `scale3` の順）、その後に残りを名前順。
  `AttributeSet` は `HashMap` なので、順序は必ずこの規則で決める
- 数値型の列は右寄せ、`Bool` と `Str` は左寄せ

### セルの書式

| 型 | 表示 |
|---|---|
| `F32` | 有効数字 4 桁（`8.000` / `1235` / `0.01250`）。固定小数で 4 桁を保てない桁（10 進指数が `-3..=3` の外）は科学表記（`1.000e-8` / `1.500e10`） |
| `Vec2` / `Vec3` / `Vec4` | 成分をカンマ区切りのタプル |
| `Color` | 4 成分（RGBA）のタプル |
| `I32` | 整数そのまま |
| `Bool` | `true` / `false` |
| `Str` | そのまま |

**非有限値（NaN / ∞）は `NaN` / `inf` / `-inf` と表示する。** 上流のゼロ除算が
見えるようにするのがこのパネルの役目なので、`0.000` に丸めて隠さない。
**同じ理由で、ゼロでない値をゼロと表示してはならない。** `1e-8` を
`0.000000` と出すのは NaN を隠すのと同じ嘘なので、そこで科学表記へ落とす。

### 表示するものが無いとき

行の代わりに 1 行の文を出し、ドメインタブは残す（どのドメインに要素があるかは
そこでしか分からないため）。

| 状態 | 出す文 |
|---|---|
| ノードが選ばれていない（選択なし / 対象がレイヤーやコンプ / 選択が今のコンプの外） | ノードを選択するとジオメトリのアトリビュートを表示します |
| 選択ノードがジオメトリ出力を持たない（`rasterize` など） | このノードはジオメトリを出力しません |
| 評価結果がまだ届いていない | 評価中… |
| そのドメインに要素が無い | このドメインに要素はありません |

**「まだ届いていない」を「出力しない」と言ってはならない。** 選択の直後の
1 フレームに、実際には出力するノードについて嘘の文が出る。

## 非対象

- **セル編集**（上記の理由により v1 では持たない）
- **属性の統計表示**（min/max/平均）。全要素走査が毎フレーム走る
- **複数選択の同時表示**。`PropertiesTarget::Nodes` の `ids` 先頭のみ
- **`instance_source` の中身**。入れ子の `Geometry` なので階層 UI になる
- **プリミティブのトポロジ表示**（`Primitive::Path` の `verts` 範囲）
