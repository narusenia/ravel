# Media Bin 仕様

> 最終更新: 2026-07-30 ／ 索引: [`../ui-spec.md`](../ui-spec.md)

プロジェクトのメディアアセット一覧。関連要件: REQ-UI-008、REQ-UI-010、
REQ-PROJ-001。設計は
[`../../implementation/media-import-plan.md`](../../implementation/media-import-plan.md)。

## 表示

- `Document.media_assets` の一覧。1 行 1 アセット
- 種別フィルタ（すべて / 映像 / 静止画 / 音声）と名前検索
- サムネイル（`ThumbnailCache`）。生成前・生成失敗時は種別アイコンにフォールバック
- 参照先が見つからないアセットはオフラインとして表示する
- 選択は `MediaSelection` Global。Properties が `MediaAsset` ターゲットに追従する
  （詳細表示は `MEDIA-6`）

## 取り込み

- File ▸ Import…（`Cmd+I`、複数選択可）と OS からのファイル D&D
- probe はバックグラウンドで行い、成功した分だけ `media_assets` に登録する。
  パスは相対 / 変数形式で記録する
- **取り込みは取り込みだけ**。レイヤーは作らない。素材をコンプに置くのは
  別の操作（下記「行の操作」と Timeline / Viewer への D&D）。バッチ全体で
  1 undo
- 同じ絶対パスは既存アセットを再利用する
- 失敗は無言にしない（workspace の通知で出す）

## レイヤー化

素材をアクティブコンプに置く経路は 1 つの実装
（`ProjectState::add_asset_layers`、変換そのものは `add_media_layers`）に
集約する。

- 置く位置は**素材長のレイヤー**。長さが不明なときはコンプ全長
- 音声つきの素材は殻に `AudioSource`（同一 asset_id + 最初の音声ストリーム）を
  設定する。映像を持たない音声ファイルは frameless な `audio` テンプレートで
  レイヤー化する
- **複数素材を一度に置いても 1 undo**（1 document commit）

## 行の操作

| 操作 | 挙動 |
|---|---|
| ダブルクリック / 右クリック ▸ レイヤーとして追加 | 再生ヘッド位置でアクティブコンプへ置く |
| 右クリック ▸ 素材からコンポジションを作成 | 素材の解像度 / fps / 長さでコンプを作る |
| 右クリック ▸ プロジェクトから削除 | 使用中なら参照しているコンプ・レイヤー名を挙げて確認する |
| Timeline / Viewer へのドラッグ | レイヤーとして置く。Timeline はポインタ位置のフレーム、Viewer は再生ヘッド位置 |

ドラッグのペイロードは**押した行 1 つ**（`DraggedAsset`）。行の描画時に確定するため、
押下で更新される選択とはずれる。**落とした時点の `MediaSelection` に対して展開する**
（掴んだ行が選択に含まれるなら選択全部、含まれないならその行だけ）。右クリックメニューと
同じ規則。オフラインの行はドラッグできない。

音声アセットは準備（デコードと出力レートへの変換）が終わるまで「準備中」を
表示する。
