# Node Graph Editor 仕様

> 最終更新: 2026-08-01 ／ 索引: [`../ui-spec.md`](../ui-spec.md)

1 つのノードネットワークを編集する。関連要件: REQ-UI-002、REQ-LAYER-011。

## 何を編集しているのか

- ネットワークは**レイヤーが所有する**（REQ-LAYER）。編集対象は
  `LayerSelection` を observe して決まり、**レイヤーが 1 つだけ選択されている
  ときにそのネットワークを開く**
- レイヤーが 0 個または 2 個以上のときは同じ「閉じた状態」（中央の
  メッセージだけ差し替え）。閉じるときは `CanvasSelection` もクリアする
- 所有パスは Comp / Layer / [Subnet...] で表され、パンくずバーに出る。
  クリックで任意の深さへ戻る
- 殻の合成チェーンが生む synthetic ノードは**描画とヒットテストの両方で
  非表示**にする
- 編集はネットワーク単位ではなく Document へ splice して commit する。
  undo / redo はパネルではなくワークスペースが Document 単位で処理する

## インタラクション

| 操作 | 割り当て |
|---|---|
| パン | スクロールホイール（修飾キー無し） / 中ボタンドラッグ / **Alt + 左ドラッグ** |
| ズーム | **Cmd（または Ctrl）+ スクロール**。カーソル位置を中心に。トラックパッドのピンチも可 |
| ノード選択 | 左クリック。Shift で追加 |
| 矩形選択 | **Shift + 左ドラッグ**。AABB 交差で判定 |
| ノード移動 | 選択後にドラッグ。**10px グリッドにスナップ** |
| 接続 | ポートからドラッグ → ドラフトのベジェ線 → 互換ポートへスナップ → エッジ追加 |
| エッジ選択 | エッジをクリック（ベジェのヒット判定は 5px 閾値） |
| 削除 | Delete / Backspace（ノード削除は接続エッジもカスケード） |
| ノード追加 | 右クリックメニュー、または検索パレット（下記「検索パレット」）。候補は registry のテンプレートから `shape.custom_path` を除いたもの（キャンバスでのみ編集可能なため） |
| Subnet へ潜る | Subnet ノードをダブルクリック |
| ビューをフィット | `F` |
| コピー / ペースト / 複製 | Cmd+C / Cmd+V / Cmd+D（複製は (20, 20) オフセット） |

- **接続の型フィルタ**: ドラッグ中は非互換ポートをスナップ候補から外す
- **単一入力制約**: 既に繋がっている入力へ接続すると既存エッジを置き換える
- ポートのヒットテストは z 順を尊重する（重なったノードで手前が勝つ）

矩形選択は Shift 開始を要求するのに開始時の選択を捨てる不具合がある
（`LOW-APP-03`）。`TOOLX-2` が Viewer 側に同じ機能を入れるとき、同じ形で直す。

## 描画

| 要素 | 内容 |
|---|---|
| 背景 | グリッドドット。ズームに応じて間隔が変わり、5px 未満では描かない |
| ノード | 角丸、テーマ背景 + ボーダー、ヘッダーに種別アイコン + ラベル（ロケール解決後。ユーザーリネームが優先） |
| ポート | 入力は左端 / 出力は右端。`DataTypeId` ごとの色 |
| ポートラベル | 入力は左寄せ / 出力は右寄せ |
| パラメータ | **`key: value` のテキスト**（スライダやドロップダウンは出さない） |
| エッジ | Bezier（S 字）/ Straight / Step の 3 スタイル。矢印付き。右クリックで切替 |
| 選択 | アクセント色のボーダー |
| Bypass | 半透明で描く。評価器は入力をパススルーする |
| 評価時間 | ノード下に表示。8ms 以上で黄、33ms 以上で赤 |
| カリング | 画面外のノードは描かない（50px マージン） |

## ノードの発見性

ノードが「何をするものか」を製品内で知るための仕組み。設計判断の経緯は
[`../../implementation/done/node-discoverability-plan.md`](../../implementation/done/node-discoverability-plan.md)。

### ラベルと説明のロケール化

- ノードのラベル / 説明 / パラメータ説明はロケールキー
  （`node.<type_key>.label` / `.description` / `.params.<name>`、
  `assets/locales/{en,ja}.toml` の `[node."<type_key>"]` テーブル）から
  解決する。組み込み 40 テンプレートすべてに en / ja の label がある
- キーが無い型は `type_key` 表示にフォールバックする（新しいノード型を
  足した瞬間にビルドも表示も壊れない）。網羅はレジストリ走査テストが
  保証する。Properties の Node Info だけは経路が異なり、登録済み型で
  キーが欠落した場合に限り生のキー文字列が出る（走査テストで到達不能）
- ユーザーがリネームしたノード（保存されたラベルがテンプレート既定と
  異なるもの）は常にそのラベルが優先される
- キーの解決は UI 側だけが行い、コア層（`ravel-core`）はロケールを
  知らない

### ホバー Popover

- ノード上に約 500ms 滞留すると詳細 Popover が開く。ノード移動・
  接続ドラッグ・矩形選択・パンの最中は開かない
- 内容: アイコン + ラベル / カテゴリ / 説明（無い型では節ごと省略）/
  入出力ポート（名前 + 型）/ パラメータ（名前 + 現在値 + 説明）。
  現在値は表示中のフレームで保存済みチャネル（定数・キーフレーム
  カーブ）から採取するだけで、Popover は評価要求を出さない。カーブを
  持たないチャネルソース（式など）は解決されず 0 表示になる
- フォーカスを奪わない（gpui-component Popover の制御モード。
  アンカーはゼロサイズの absolute wrapper）
- 同じ説明にはキーボードだけでも到達できる: 選択中ノードの説明は
  Properties の Node Info セクションにも出る

### 検索パレット

- 発動: `Tab`（開閉トグル。キャンバス中央に出る）/ 空所の
  ダブルクリック（カーソル位置）/ 接続ドラッグのワイヤーを空所に
  ドロップ（その場合は**接続可能な型のみ**が候補になる）
- インクリメンタル検索の対象はロケール解決後の label と description。
  大小文字を区別しない部分一致で、label の一致は description のみの
  一致より上位に並ぶ
- カテゴリのフィルタチップを持つ（その回の候補に存在するカテゴリだけ
  出る）。最近使った型（セッション内メモリ、最大 10 件、永続化なし）は
  **同じ一致段の中で**上位に並ぶ（label 一致 > description 一致の順位が
  先に効く）
- 候補行には種別アイコン・ラベル・カテゴリを出す。↑↓ で選択、
  Enter で確定、Escape で閉じる
- パレットは使い捨てで、閉じると検索語・選択・フィルタは残らない
- 候補の列挙とノード生成・配線は右クリックメニューと同じ経路を共有
  し、確定はメニューからの追加と同じ Document 変更（1 undo）になる
- 右クリックの追加メニューはパレットに置き換えられず残る

### 種別アイコン

- アイコンは `type_key` に紐づく。対応表は `ravel-app` の
  `RavelIcon::for_node_type(type_key, category)` 1 箇所だけで、
  コア層はアイコンを知らない
- 未登録の `type_key` はカテゴリ既定アイコン
  （`RavelIcon::for_category`）にフォールバックする。カテゴリも不明な
  場合は汎用の `RavelIcon::NodeGraph` に落ちる
- 出す場所: ノードヘッダ（カテゴリ色でキャンバスに直接描画。描画
  サイズは 8〜32px の 5 段階に量子化し、6px 未満では省略。ヘッダの
  高さとノード幅は変わらない）、ノード追加コンテキストメニュー、
  Outliner のノード行、検索パレットの候補行
