# Properties Inspector 仕様

> 最終更新: 2026-07-31 ／ 索引: [`../ui-spec.md`](../ui-spec.md)

選択されている対象を編集する。関連要件: REQ-UI-002、REQ-UI-012、REQ-CORE-002。

## 対象の決まり方

表示対象は `SelectedPropertiesTarget` Global が持つ。**Global は対象を
「識別」するだけで値は持たない** — 値は毎回ライブの Document から解決する
（stale な値を持たないため）。

| 対象 | 誰が設定するか | 編集 |
|---|---|---|
| `Empty` | 選択が無いとき | — |
| `Nodes { network, ids }` | Node Editor / Viewer の選択 | ✅ |
| `Layer { comp, layer }` | Timeline / Outliner のレイヤー選択（1 枚） | ✅ |
| `Layers { comp, layer_ids }` | 同（2 枚以上） | 🔲 読み取り専用（件数と一致する値のみ） |
| `Composition { comp }` | Outliner のコンプ行、コンプ管理コマンド | ✅ |
| `MediaAsset { id }` | MediaBin の選択 | 🔲 プレースホルダ（`MEDIA-6`） |

複数レイヤー選択を `Layer` と別 variant にしているのは、**一括編集がどの
レイヤーにも適用先を持たないウィジェットから漏れ出さないようにする**ため。

## セクション

対象によって出る節が変わる。

| 節 | 内容 |
|---|---|
| Layer | 名前、ラベル |
| Timing | 開始フレーム、表示区間（in / out） |
| Transform | anchor / position / scale / rotation（各成分がアニメーション可能なチャネル） |
| Compositing | 不透明度、ブレンドモード、調整レイヤーフラグ、solo / mute / lock |
| Audio | ゲイン、フェード（音声を持つ殻のみ） |
| Composition | 名前、解像度、フレームレート、尺、背景色 |
| Node Info | ID、型、ラベル |
| Parameters | ノードのパラメータ |

## 値の編集

- **数値はスクラブ入力**: 横ドラッグで値を変える。カーソルは `ResizeLeftRight`。
  ダブルクリック（またはクリック）で直接入力に切り替わる。パラメータ範囲
  （`ParamRange`）があればソフトクランプする
- **列挙は dropdown**: `param_options` を持つ文字列パラメータは自由入力にしない
- **キーフレーム菱形**: 各アニメーション可能フィールドの左に置く。現在フレームに
  キーがあれば塗り、無ければ枠のみ。クリックで現在フレームのキーを追加 / 削除
- **ポートトグル**: パラメータを入力ポートとして露出する（未露出 / 露出 /
  接続済みの 3 状態）。接続済みのパラメータは値の編集を受け付けない
- **カーブはインライン展開**: カーブパラメータ（`field.curve_remap` の
  `points` など）は折り畳み時にサムネイルを出し、行クリックで直下に
  カーブエディタを開く。点はドラッグで移動、空所のダブルクリックで追加、
  点のダブルクリックで削除（最少 2 点は残す）。展開高さは下端のハンドルを
  ドラッグして変える。**複数行を同時に展開できる**（排他にしない）
- **展開状態は Document に入らない**。どの行が開いているか・どの高さかは
  パネルのビュー状態で、undo には積まれず undo で変わりもしない。表示対象が
  変わると捨てる（`points` のような素のキーはどのノードのものか区別しない）
- スクラブ 1 ジェスチャ = 1 undo。ドラッグ中はプレビューを適用し、離したときに
  1 スナップショットを積む。カーブの点ドラッグも同じ規約
- キーフレーム付きチャネルの編集は**チャネルを平坦化しない**。現在フレームに
  キーを挿入 / 更新する
