# 書き出しダイアログ / Render Queue パネル

> 索引: [`../ui-spec.md`](../ui-spec.md)

`File ▸ Export…`（`CommandId::FileExport`）で開くダイアログと、投入したジョブを
並べる Render Queue パネルの**意図した挙動**。実装状況の正は
[`../../ui-impl-status.md`](../../ui-impl-status.md)、CLI からの同じ書き出しは
[`../../dev/render-cli.md`](../../dev/render-cli.md)、設計の根拠は
[`../../implementation/render-export-plan.md`](../../implementation/render-export-plan.md)。

関連要件: REQ-RENDER-001（キューベースバックグラウンドレンダリング）、
REQ-RENDER-005（CLI ヘッドレスレンダリング）。

## 原則

- **GUI と CLI は同じワーカー・同じエンコーダを通る。** ダイアログは
  「解決済みジョブ記述」を組み立てる層でしかなく、書ける形式の判定・出力
  ファイル名・上書き規則・音声の併置は CLI と共通の 1 実装が決める。画面から
  出した成果物とコマンドラインから出した成果物が違ってはならない
- **キューはパネルではなくセッションが持つ。** パネルを閉じてもレンダリングは
  続き、開き直せば走っているジョブが見える。パネルは表示器であって所有者ではない
- **できないことは隠さず理由を出す。** 使えない形式を一覧から消すと、ユーザーは
  存在しないメニュー項目を探し続ける
- **投入前に落とせるものは投入前に落とす。** ただし最終判定はワーカー側。
  ダイアログの検査は「キューに失敗行が出る」代わりに「その場で文が出る」ための
  ものであり、真偽の権威ではない

## 書き出しダイアログ

| 項目 | 挙動 |
|---|---|
| 対象コンプ | プロジェクトのコンポジションから選ぶ。開いたときのアクティブコンプが初期値 |
| フレーム範囲 | **画面上は両端 inclusive**。内部の半開区間への変換はダイアログが行う |
| 形式 | 実行時列挙（`available_encoders`）から作る。PNG / EXR は常に選べる |
| PNG ビット深度 | 8 / 16 |
| 出力先 | ディレクトリ。ファイル名は接頭辞・接尾辞・ゼロ詰め桁数から組み立てる |
| 上書き | 既定は拒否。明示的なオプト・インでのみ許す |
| 音声 | 音声を持つコンポでは既定で書く。外すと映像だけになる |

- **形式一覧は使えないものも出し、使えない理由を添える。** 「この環境の
  FFmpeg に libaom がない」と「AV1 という形式が無い」は別の事実
- **動画コンテナは列挙には出るが選べない。** 書き手がまだ無いため。これは
  環境の欠落ではなく Ravel の欠落なので、文面もそう読めること
  （CLI 側の同じ拒否は `codec-no-writer`）
- **音声の有無は選ばれているコンプに追随する。** ダイアログは開いたコンプより
  長生きするので、開いた瞬間に 1 度だけ判定した答えを持ち回ってはならない
  （音のあるプロジェクトが黙って無音で書き出される道になる）
- 空のコンポジション、`out < in` の範囲は投入前に拒否する
- **キャンセルしたダイアログは何もしない。** OK を押すまでキューに何も届かない

## Render Queue パネル

投入したジョブが 1 行ずつ並ぶ。行は**投入した瞬間から**存在し、ワーカーが
拾う前は「待機中」で始まる。

| 列 | 内容 |
|---|---|
| 対象 | コンポジション名と出力先ディレクトリ（**投入時点のもの**） |
| 進捗 | バーと「n / m フレーム」 |
| 状態 | 待機中 / 実行中 / 完了 / 中止 / 失敗 |
| 操作 | 中止（待機中・実行中の行だけ） |

- **進捗の算術は CLI と共有する**（`JobProgress`）。パネル専用の数え方を
  持たない
- **中止はフレーム境界で効き、書きかけの出力を消す。** 完了・失敗・中止済みの
  行に中止ボタンは出さない
- 失敗行は診断を行の下に出す。状態語は翻訳され、診断は翻訳されない
  （スクリプトが読むものと人が読むものを分ける、CLI と同じ規約）
- 「完了分を消す」は**終わった行だけ**を畳む。走っているジョブは残る
- 行はレンダリング中の編集の影響を受けない。ジョブは投入時のドキュメント
  スナップショットを持つので、**レンダー中に編集しても出力は投入時の内容**

## 未実装

- **ジョブの一時停止 / 再開**（REQ-RENDER-001 の受入条件）。今あるのは中止のみ。
  引き受ける計画は未定
- **ジョブの優先度変更・並べ替え**（同上）。キューは投入順に順次実行する
- **動画コンテナ出力**。ダイアログにもコーデック一覧にも出るが選べない。
  `render-export-plan.md` の非対象
- **カラーマネジメント**（REQ-RENDER-003 / OCIO）。Viewer・PNG・EXR・将来の
  動画の 4 経路が一致することを優先しており、出力に伝達関数は適用しない
