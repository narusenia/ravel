# Timeline 仕様

> 最終更新: 2026-07-30 ／ 索引: [`../ui-spec.md`](../ui-spec.md)

アクティブコンポジションの時間ビュー。関連要件: REQ-UI-003、REQ-UI-012、
REQ-LAYER。

> **旧仕様との違い**: v1 の「Sequence ノードの糖衣 UI」「トラック / クリップ
> エディタ」「Timeline の二面性（Sequence 選択時は NLE、それ以外はドープシート）」は
> **実装されていない設計**。Timeline は常に `Composition` の `Layer` を並べ、
> ドープシートとカーブエディタはその**表示モード**として切り替わる。

## 構造

```text
┌──────────────────────────────────────────────────────────────┐
│ ▶ ■ │ 00:00:12:03 │ F │ [Dopesheet | Graph]                 │ ← トランスポート
├──────────────┬───────────────────────────────────────────────┤
│              │ |    |    |    |    |    |    |    |          │ ← ルーラー（フレーム / TC）
├──────────────┼───────────────────────────────────────────────┤
│ ▾ title  SML │        ▐████████████▌                         │ ← レイヤーバー
│   ▾ Transform│                                               │
│     Position │        ◆      ◆         ◆                     │ ← キーフレーム行
│ ▸ bg     SML │  ▐██████████████████████████▌                 │
└──────────────┴───────────────────────────────────────────────┘
   レイヤーヘッダー          レーン（1 枚の canvas 描画）
```

- 左のヘッダー列と右のレーンは横スクロールを共有しない（ヘッダーは固定幅）
- レーンは 1 枚の `canvas` に描く。ヘッダー列の構築とレーンの描画はどちらも
  可視 y 範囲に限られる（ヘッダーは `ScrollHandle`、キャンバスは paint 時の
  `content_mask()`）。折り畳まれたレイヤーの行モデルはそもそも作らない

## トランスポート

| 要素 | 内容 |
|---|---|
| 再生 / 一時停止 | `Space`。停止は `K` |
| フレーム送り / 戻し | `←` / `→` |
| タイムコード表示 | クリックで直接入力に切り替わる。Esc で取り消し |
| フォロー再生（`F` トグル） | 再生ヘッドが可視範囲外に出たらスクロールを追従させる |
| 表示モード切替 | ドープシート / グラフ（カーブエディタ） |
| BPM グリッド | `BPM` トグルとテンポ・1 拍目のフレーム（下の「BPM グリッド」節） |
| ループ範囲 | `B` / `N` で開始点・終了点、`Alt+B` で解除（下の「ループ範囲」節） |

再生位置のクロックは音声トラックがありデバイスが稼働中はオーディオ、
それ以外は wall clock。コンポジション終端では自動的に一時停止する
（ループ範囲があるときは折り返す）。

## ルーラーとスクラブ

- ルーラー上の mousedown で再生ヘッドを移動し、**そのままドラッグを続けると
  ポインタがルーラーの外に出てもスクラブが続く**（`ScrubInput` と同じ契約）
- スクラブは Document を変更しないので undo に積まない
- **`Shift` を押している間は表示中のキーフレームに吸着する**（押下・ドラッグの
  両方）。吸着距離は 8px の**ピクセル半径**で、ズームに依らず同じ操作感になる。
  等距離なら手前のフレームが勝つ
  - 「表示中」は**画面に出ている行**の意味。畳んだレイヤーのキーには吸われず、
    絞り込みで消えている行のキーにも吸われない
    （`TimelinePanel::visible_property_rows` が唯一の出所）。プロパティ行を
    畳んでいても、その行はチャネルのキーをまとめて描くので候補に残る
  - コンポジションフレーム 0 より前のキーは候補にしない（再生ヘッドは符号なし）
- 目盛りは minor / major の 2 段。フレームレートが minor ステップで割り切れない
  場合に major が描かれなくなる不具合がある（`LOW-APP-05`）

## コンポジション終端

Duration の外は**帯を敷いて落とす**。ルーラーとレーンの両方に敷き、終端の
フレームには 1px の線を引く。

- **ズームは終端で止めない。** 範囲外を見たい場面があるので、見えなくするの
  ではなく見分けが付くようにする
- グラフモード（カーブエディタ）には敷かない

## ループ範囲

イン / アウトで区切った区間を繰り返し再生する（AE のワークエリア相当）。

| 項目 | 内容 |
|---|---|
| 開始点 / 終了点 | 再生ヘッドの位置に `B` / `N`。メニューは 再生 ▸ ループ開始点 / 終了点を設定 |
| 解除 | `Alt+B`。ルーラーの `Alt`+クリック（動かさずに離す）でも解除 |
| ルーラー操作 | `Alt`+ドラッグ。押した位置と離した位置が両端で、左右どちらへ引いてもよい |
| 描く場所 | ルーラーのみ。両端に 2px の線を引く |

- **範囲はコンポジション単位**。レイヤーごとには持たない。コンポジションを
  切り替えれば、そのコンポジションの範囲に切り替わる
- 終了点のフレーム**も再生してから**折り返す（区間は閉区間）
- **範囲外へシークするとループが外れる。** 再生ヘッドを黙って引き戻さない —
  クリックが効かなかったように見えるため。フレーム送りで範囲を出たときも同じ
- コンポジションを短くすると終了点は中へ引き戻され、開始点まで外へ出たら
  範囲そのものが消える
- 停止（`K`）はループがあるとき開始点へ戻る。0 まで戻すと次の再生でループが
  外れてしまうため
- 音声は**ミキサーの読み出し位置を折り返す**ので、折り返しでシークは起きず
  途切れない。ループの設定・解除そのものはシークなので、そこでは切れる
- 状態は BPM グリッドと同じく `ui_state.json` に載る。
  **プロジェクトを人に渡してもループ範囲は付いていかない**（2026-08-09 に AE の
  ワークエリアが `.aep` に入ることを確認したうえで、作業の都合であって作品の
  属性ではないと判断した）

## キャッシュ帯

ルーラーの下端に、**出力段のフレームキャッシュが今持っているフレーム**を
3px の帯で描く（`CACHE-6`）。AE のキャッシュバーに当たる。

| 項目 | 内容 |
|---|---|
| 描く場所 | ルーラーのみ、下端の境界線の 1px 上 |
| 色 | 緑（`success`）= RAM 層。ディスク層（青）は層自体が未実装（`CACHE-11`） |
| 範囲 | `SharedFrameCache::cached_ranges(comp, &EvalContext)` の返り値そのまま。連続フレームは 1 本にまとめる |

- **ビューアが次に投げる `EvalContext` そのもの**で引く。照合は実際のヒット判定
  （`CacheIdentity::mismatch`）と同じで、解像度・精度だけでなく品質・fps・
  コンプ解像度も見る。プレビュー解像度を切り替えれば帯も切り替わる — 軸が
  1 つでも違うエントリはスクラブで当たらないので、それを緑にすると帯が嘘になる
- 伸びるのは**再生・スクラブで通ったところ**と、**手が止まっている間に
  先読みが埋めた前方**（`CACHE-9`）。先読みは評価ワーカーがしばらく何も
  要求されていないときだけ走り、次の操作で止まる。ビューアの表示は
  変わらない — 先読みはキャッシュに書くだけ
- 編集すると帯は**その場で**消える（評価の完了を待たない）。空コンポジション・
  コンパイルエラーのように評価が走らない経路でも消す。消えるのは**編集が
  届く範囲だけ**で、ノードを名指しした編集はその所有レイヤーの時間範囲
  （と precomp 経由で親コンプの該当レイヤーの範囲）に留まる（`CACHE-7`）
- サブフレーム位置（モーションブラーのシャッターサンプル）は帯にしない。
  再生ヘッドが乗れない位置なので、丸めて緑にすると当たらないフレームを
  当たると言うことになる
- **帯のために再描画を増やさない。** 更新はグローバルへの書き込みで、
  範囲が変わったときだけ書く。パネルはこのグローバルを購読せず、
  再生ヘッドや文書の更新で走る再描画のついでに読む（`HIGH-21`）

## BPM グリッド

音楽に合わせる用途の拍グリッド。**フレームグリッドとは別物で、同時に出せる**。

| 項目 | 内容 |
|---|---|
| on / off | トランスポートの `BPM` トグル |
| テンポ | `BPM` の右の読み取り欄。クリックで直接入力（Enter で確定、Esc / blur で取り消し） |
| 1 拍目のフレーム | その右の `f` 付き読み取り欄。同じ操作 |
| 描く場所 | ルーラーとレーン（バー表示のとき）。グラフモードには描かない |

- 拍の位置は `offset + 拍番号 × (fps × 60 / BPM)`。**フレームに丸めない** —
  丸めるとフレームグリッドに吸い付き、数小節で 1 拍ぶんずれる。丸めが起きるの
  は描画のピクセル位置だけ
- 拍の間隔が 4px を切ったら描かない（線ではなく塗りつぶしになるため）
- テンポは 1〜999 BPM に丸め込む。0 や負の値は帯の計算が壊れる
- 状態は**コンポジションの属性ではなく UI 状態**で、`ui_state.json` に載る
  （絵に影響しないので `.ravprj` の `format_version` は上げない）。したがって
  **プロジェクトを保存したときに残り、保存せずに終了すれば残らない**

## ズームとスクロール

| 操作 | 割り当て |
|---|---|
| 水平ズーム | Cmd（または Ctrl）+ スクロール。ポインタ下のフレームを固定して拡大縮小 |
| 横スクロール | スクロールホイール |
| 縦スクロール | レーン領域の縦スクロール |

ズームのアンカーがウィンドウ空間で計算されている不具合がある（`HIGH-19`）。
カーブエディタの縦ズームは未実装（`PARAM-5` / `MED-APP-17`）。

## レイヤーヘッダー

- 名前、展開矢印、`S` / `M` / `L`（solo / mute / lock）のトグル
- 行のクリックでレイヤー選択。Shift で範囲、Cmd でトグル
- **縦ドラッグでスタックの並べ替え**（マウスアップでコミット。修飾キー付きの
  クリックは選択を作るだけで並べ替えない）
- 展開するとプロパティツリーが出る: プロパティグループ → チャネル行。
  チャネル行にはキーフレームのナビゲーションボタンが付く
- トグルの操作は**選択全体に適用**される（その行が選択に含まれるとき）

### 素材のドロップ

MediaBin からレイヤースタックへドロップすると、**ポインタ位置のフレームから**
始まるレイヤーになる（レイヤーヘッダーの上に落としたときは表示中の先頭フレーム）。
スタック位置は他のレイヤー追加と同じく一番上。複数素材のドロップは 1 undo。

### プロパティ行

シェルのグループを AE の並びで出し、その後にキーフレームを持つネットワーク
パラメータが続く（`ravel_ui::keyframes::property_rows`）。

| 行 | 成分 | 出る条件 |
|---|---|---|
| アンカーポイント | `X` / `Y` | 常時 |
| 位置 | `X` / `Y` | 常時 |
| スケール | `X` / `Y` | 常時 |
| 回転 | 1 | 常時 |
| 不透明度 | 1 | 常時 |
| ゲイン | 1 | 音声を持つレイヤーのみ |
| ネットワークパラメータ | 1〜4 | いずれかの成分がキーフレームを持つとき |
| ネットワークパラメータ（Int） | 1 | `IntChannel` がキーフレームを持つとき |
| ネットワークパラメータ（String） | 1 | `StringSteps` がキーを持つとき |

Int の行は f32 チャネルそのものなので編集も表示も f32 の単成分行と同じで、
違うのはグラフモードの描画だけ（階段）。String の行は保持キーの列で、
**追加・移動・削除だけ**ができる。識別子パラメータ
（`layer.ref` の `layer`、`precomp` の `comp_id`、メディアの `asset_id`）は
アニメーションさせないので行を出さない。

### チャネル行の値スクラブ

チャネル行の右端に**その成分の現在値**を出し、そこを直接ドラッグして変える。
Properties へ往復せずに値を触るための経路。

- 挙動は Properties のスクラブと同じ（`widgets/scrub_input.rs`）。
  感度は UI レンジ由来、clamp は hard レンジ、Shift = 10x / Cmd = 0.1x、
  ドラッグせずに離すと数値入力になる
- **1 ジェスチャ 1 undo**。ドラッグ中の `Change` は undo を積まず、
  終端の `Commit` が 1 スナップショットを記録する
- 値は**再生ヘッドのレイヤーローカルフレーム**に書く。キーの打たれている
  チャネルはそのフレームのキーが更新され（無ければ挿入され）、定数の
  チャネルは定数が置き換わる（`ravel_ui::keyframes::set_channel_value`。
  Properties と同じ 1 本の書き込み経路）
- **1 ジェスチャが書くフレームは 1 つ。** フレームはジェスチャの最初の
  イベントで固定する。再生中は再生ヘッドがドラッグの下で動くので、
  追従させると掴んだフレームではなく通過したフレーム全部にキーが散る
- **ロックの判定はジェスチャ開始時のみ。** 途中でロックされても受け付けた
  ジェスチャは最後まで走る（ライブの値がすでに文書にあるので、途中で
  拒むとその値が自分の undo ステップを持たないまま残る）。
  Timeline 自身のロック操作は**先に進行中のスクラブを確定**させるので、
  ロックのコミットがライブの値を巻き込まない
- **ジェスチャの終わり方は 1 箇所に集約する。** ポインタを離して
  ウィジェット自身が終わる場合を除き、次の 3 つは同じ経路を通る:
  行がツリーから消えた / パネルが他のコミットをする直前 / **パネル自体が
  消える**。値が動いていなければ `Commit` は**そもそも飛ばない**ので、
  イベント頼みの後始末は成立しない — コミットするかしないかの判断も、
  ウィジェットと確保したフレームの破棄も、その 1 箇所で行う
- 行が絞り込み・undo・他パネルの編集でツリーから消えると、その場で
  ジェスチャを確定する。消えた行にはもう掴む要素も離す要素も無いので、
  ドラッグのまま残すとポインタから永久に終われなくなる
- **パネルが破棄されたときはライブの値をコミットする**（破棄しない）。
  ユーザーは値を動かして結果を見ているので、ペインが閉じたことは取り消しの
  意思表示ではない。コミットすれば押せる undo が 1 つ残るが、破棄すると
  意図した編集が黙って消え、ライブ文書を共有する他パネルの未コミットの
  作業も道連れになる
- **単位は Properties と同じ**: スケールと不透明度はパーセント、他は生値。
  ネットワークパラメータは生値（レンジ情報はノード側にあり、行が持つ
  ノード id とキーからは引けない）。グラフモードの縦軸は生値のままなので、
  スケールと不透明度はグラフの目盛とこの表示がずれる
- **式・ブレンド・ノード出力に駆動された成分には値を出さない。**
  書き込み経路がその成分を拒むので、動かない操作子を置かない
- 値の押下はスクラブの開始であって、グラフ表示のチャネル選択ではない
  （行本体のクリックは従来どおり選択する）
- ドラッグ中にウィジェットを**捨てない**。捨てると終端の `Commit` が届かず
  undo が 1 つ飛ぶ（`HIGH-28` と同型の欠陥）。行が消えるときは捨てる前に
  確定する（上記）
- ウィジェットの生成・破棄・値の更新は**描画ではなく木が変わった経路**で行う
  （文書同期、再生ヘッド移動、展開の開閉、絞り込み）。`render` は
  出来上がったものを読むだけで、エンティティも購読も作らない
- **タブが手前にない間は文書同期そのものを走らせない。** 飛ばした分は
  表に戻ったときに 1 回で追いつく（[`../ui-spec.md`](../ui-spec.md) の設計原則）
- ウィジェットの同一性は**コンプ + レイヤー + 行 + 成分**。`LayerId` は
  コンプをまたいで再利用されるので、コンプを切り替えたときに前のコンプの
  ウィジェットが使い回されると、画面に出ていないコンプのレイヤーを書き換える
  （書き込み先はウィジェットを作った時点のコンプに固定されている）

### 行の絞り込み（AE の reveal）

キーで**行を絞り込む**。行の生成そのものは変わらず、フィルタが 1 枚かかる。

| chord | 出る行 |
|---|---|
| `U` | キーフレームを持つ行 |
| `A` / `P` / `S` / `R` / `T` / `L` | アンカーポイント / 位置 / スケール / 回転 / 不透明度 / ゲイン |
| `Alt+U` | 既定から変更済みの行 |
| `Alt+E` | 式に駆動されている行（ブレンド越しの式も含む） |

- **修飾なしは置換**、`Shift` 併用は現在の絞り込みに**足す**。同じキーを
  もう一度押すと全表示に戻る
- 絞り込みはパネルの状態なので、**レイヤーを選び直しても保たれる**
- 該当行の無いレイヤーはその行が空になるだけ（エラーにしない）
- AE の `E`（エフェクト）、`LL`（波形）、マスク各種は**入れない**。
  Ravel の効果はノードネットワークで行に対応する概念が無く（そのパラメータ行は
  `U` / `Alt+U` に含まれる）、波形は未実装（`AUDIO-5`）、マスクは無い
- 絞り込みは描画・ヒットテスト・ラバーバンド・高さ計算の**すべて**に効く
  （`TimelinePanel::visible_property_rows` の 1 経路。`MED-APP-13`）
- 展開は変えない。AE の `U` は選択レイヤーを開くが、ここでは開いている
  レイヤーのツリーを絞るだけ
- **`Alt+E` が拾えるのは行のある行だけ。** ネットワークのパラメータは
  キーフレームを持って初めて行になる（`property_rows`）ので、**一度も
  キーフレームを打たずに式だけ付けたパラメータには絞り込む行が無い**。
  行の生成を広げるのはこのフィルタの仕事ではない — 絞り込み中だけでなく
  全員のツリーが変わってしまう
- 「式を持つ」の判定は Properties の式バッジと**同じ 1 つの定義**
  （`properties::expression::source_has_expression`）。ブレンドの中の式を
  片方のパネルだけが駆動と見なす、という食い違いを作らない

## レイヤーバー

| 領域 | 操作 |
|---|---|
| 本体 | ドラッグで `start_frame` を移動 |
| 左右の端（各 6px） | ドラッグで表示区間をトリム（in / out。`TRIM_HANDLE_PX`） |
| ロックされたレイヤー | 移動・トリムを受け付けず、`OperationNotAllowed` カーソルで示す |

- 音声を持つレイヤーは準備中のあいだ「準備中」を表示する
- 波形表示は未実装（`AUDIO-5`）
- ドラッグは 1 ジェスチャ 1 undo
- **移動もトリムも選択全体に適用される**（掴んだバーが選択に含まれるとき。
  トグル・削除・複写と同じ規約）。トリムの制限は**レイヤーごとに自分の
  表示区間**で掛かるので、短いレイヤーが止まっても他は動き続ける。
  ロックされたレイヤーは対象から外れる
- **選択済みのバーを修飾なしで押しても選択は保たれる**（掴んだ集合を
  そのまま動かすため）。動かさずに離したときだけ、そのバー 1 枚に絞る。
  ジェスチャが始まらない押下（ロックされたレイヤー、バーを外した押下）は
  普通のクリックなので、その場で 1 枚に絞る

## プレイヘッド基準のレイヤー操作

AE 相当の 4 つ。キーバインドは Timeline のキーコンテキストに載っている
（[`keybindings.md`](keybindings.md)）。**掴んだ行の規約と同じく選択全体に
効く**（トグル・削除・複写・バーのドラッグと同じ `operation_targets`）。

| 操作 | chord | 意味 |
|---|---|---|
| レイヤーを分割 | `Cmd+Shift+D` | プレイヘッドでレイヤーを 2 枚に割る |
| 始端をプレイヘッドへ | `[` | 尺を変えずにレイヤーを動かし、始端を合わせる |
| 終端をプレイヘッドへ | `]` | 同じく、半開区間の終端を合わせる |
| 始端 / 終端へ移動 | `I` / `O` | 選択の最も早い始端 / 最も遅い終端へプレイヘッドを飛ばす |

- **分割**は元のレイヤーを前半（`out_frame` を切れ目まで縮める）にし、後半を
  `Layer::duplicate_with_fresh_ids` の複製として真上に挿す。名前は変えない
  （複製ではなく切っただけなので `" copy"` は付かない）
  - **中身は一切書き換えない。** コンポジション時刻からレイヤーローカル時刻への
    写像は `comp - start_frame + in_frame` で、後半は `start_frame` と
    `in_frame` を同じ量だけ動かすので写像が変わらない。キーフレーム・
    ネットワーク・殻のチャネル・音声ソースはそのまま、2 枚は**元の時間範囲を
    過不足なく覆う**
  - プレイヘッドがレイヤーの内側に**厳密に**入っていないときは何もしない
    （端で切ると空のレイヤーができる）。ロックされたレイヤーも対象外
  - 選択全体で 1 undo。分割後は後半のレイヤー群が選択される
  - 音声のフェードイン / フェードアウトのフレーム数は両方の殻に複写されるので、
    切れ目で改めてフェードが掛かる
- `]` は**半開区間の終端**を合わせる。つまり最後に見えるフレームはプレイヘッドの
  1 つ手前で、`]` の次のレイヤーに `[` を打つと隙間も重なりも無く繋がる
- 移動系（`[` / `]`）はロックされたレイヤーを動かさない。ロックは**Document
  側で見る**（パネルの鏡は commit を 1 flush 遅れて追う）
- `I` / `O` はプレイヘッドしか動かさないので、進行中の値スクラブを止めない
  （スクラブは開始時のフレームを掴んだままなので巻き込まれない）

## キーフレーム

- チャネル行に菱形で表示する。ドラッグでレイヤーローカルのフレームを移動
- 空白のドラッグでラバーバンド選択（Shift で追加）
- 補間の切り替え: Bezier / Linear / Step（Action 経由）。**保持キー
  （`StringSteps` の行）には出さない** — 保持値に中間値が無いので選ぶものが
  無い。保持キーが選択に 1 つ混ざった時点で出口が閉じる:
  **コンテキストメニューの補間サブメニューは現れず**、グラフモードの
  ツールバーの 3 ボタンは**無効化される**（何も選択していないときと同じ
  見え方。ツールバーは行ごとの制御ではないので、選択の種類で消えたり
  現れたりしない）
- Delete で選択キーフレームを削除
- ラバーバンドが負のコンポジションフレームにある不可視キーを拾う不具合がある
  （`LOW-APP-04`）

## グラフモード（カーブエディタ）

- チャネルの値を時間軸に対して曲線で表示・編集する
- **Int の行は丸めた値の階段**として描く。段の境界は `round()` が変わる
  フレームで、制御点は f32 のままなので掴んで動かすと段が動く。
  可視範囲が描画のサンプル予算より広いときは、立ち上がりは
  サンプルされたフレームに寄る（最大 1 サンプル分遅れる。曲線を折れ線で
  描くのと同じ近似で、段の幅が半ピクセルを切る領域でしか起きない）
- **String の行は出ない** — 保持キーに曲線が無い
- アンカーのドラッグでフレームと値を同時に変更、タンジェントのドラッグで
  ベジェハンドルを編集（既定は対称連動、**Alt で分離**）
- 空白のドラッグでラバーバンド選択
- ダブルクリックでキーフレームを追加
- `Channel4` が常に Color として描かれる不具合がある（`MED-APP-19`）

## 翻訳しない表記

Timeline の一部の文字は**言語に依存しない記法**として、ロケールカタログを
通さずそのまま描く。意味は必ず別の要素（ツールチップ、行ラベル、
プロパティ行）がローカライズされた語で伝える。

| 表記 | 意味 | ローカライズされた対 |
|---|---|---|
| `f` | フレーム数の単位（`120f`、`300f`） | Properties の Duration 行（`properties.value.duration_frames`） |
| `fps` | frames per second | Composition 設定のフレームレート欄 |
| `S` / `M` / `L` | solo / mute / lock のトグル | `timeline.toggle.solo` / `.mute` / `.lock` のツールチップ |
| `F` | フォロー再生のトグル | `timeline.toggle.follow_playhead` のツールチップ |
| `BPM` | 拍グリッドのトグル | `timeline.bpm.toggle` のツールチップ |
| `X` / `Y` | 成分チャネルの軸 | 親のプロパティ行（`timeline.property.position` など） |
| `R` / `G` / `B` / `A` | カラーチャネルの成分 | 親のプロパティ行（ノード名 · パラメータ名） |

語で名づけられる成分（回転、不透明度、ゲイン、単一チャネルの「値」）は
記法ではないのでロケールキーで持つ（`timeline.property.*` と
`timeline.channel.value`）。`ravel-ui` は i18n に依存しないため、
`PropertyRow::channel_names` はキーと記法が混ざった配列で、
`ravel-app` の `channel_name_label` が表示境界で解決する
（カタログに無い文字列はそのまま通るので、記法は素通りする）。
