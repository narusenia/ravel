# Timeline 仕様

> 最終更新: 2026-07-30 ／ 索引: [`../ui-spec.md`](../ui-spec.md)

アクティブコンポジションの時間ビュー。関連要件: REQ-UI-003、REQ-UI-012、
REQ-LAYER。

> **旧仕様との違い**: v1 の「Sequence ノードの糖衣 UI」「トラック / クリップ
> エディタ」「Timeline の二面性（Sequence 選択時は NLE、それ以外はドープシート）」は
> **実装されていない設計**。Timeline は常に `Composition` の `Layer` を並べ、
> ドープシートとカーブエディタはその**表示モード**として切り替わる。

## 構造

```text
┌──────────────────────────────────────────────────────────────┐
│ ▶ ■ │ 00:00:12:03 │ F │ [Dopesheet | Graph]                 │ ← トランスポート
├──────────────┬───────────────────────────────────────────────┤
│              │ |    |    |    |    |    |    |    |          │ ← ルーラー（フレーム / TC）
├──────────────┼───────────────────────────────────────────────┤
│ ▾ title  SML │        ▐████████████▌                         │ ← レイヤーバー
│   ▾ Transform│                                               │
│     Position │        ◆      ◆         ◆                     │ ← キーフレーム行
│ ▸ bg     SML │  ▐██████████████████████████▌                 │
└──────────────┴───────────────────────────────────────────────┘
   レイヤーヘッダー          レーン（1 枚の canvas 描画）
```

- 左のヘッダー列と右のレーンは横スクロールを共有しない（ヘッダーは固定幅）
- レーンは 1 枚の `canvas` に描く。行の仮想化は未実装（`MED-UI-03`）

## トランスポート

| 要素 | 内容 |
|---|---|
| 再生 / 一時停止 | `Space`。停止は `K` |
| フレーム送り / 戻し | `←` / `→` |
| タイムコード表示 | クリックで直接入力に切り替わる。Esc で取り消し |
| フォロー再生（`F` トグル） | 再生ヘッドが可視範囲外に出たらスクロールを追従させる |
| 表示モード切替 | ドープシート / グラフ（カーブエディタ） |

再生位置のクロックは音声トラックがありデバイスが稼働中はオーディオ、
それ以外は wall clock。コンポジション終端では自動的に一時停止する。

## ルーラーとスクラブ

- ルーラー上の mousedown で再生ヘッドを移動し、**そのままドラッグを続けると
  ポインタがルーラーの外に出てもスクラブが続く**（`ScrubInput` と同じ契約）
- スクラブは Document を変更しないので undo に積まない
- 目盛りは minor / major の 2 段。フレームレートが minor ステップで割り切れない
  場合に major が描かれなくなる不具合がある（`LOW-APP-05`）

## ズームとスクロール

| 操作 | 割り当て |
|---|---|
| 水平ズーム | Cmd（または Ctrl）+ スクロール。ポインタ下のフレームを固定して拡大縮小 |
| 横スクロール | スクロールホイール |
| 縦スクロール | レーン領域の縦スクロール |

ズームのアンカーがウィンドウ空間で計算されている不具合がある（`HIGH-19`）。
カーブエディタの縦ズームは未実装（`PARAM-5` / `MED-APP-17`）。

## レイヤーヘッダー

- 名前、展開矢印、`S` / `M` / `L`（solo / mute / lock）のトグル
- 行のクリックでレイヤー選択。Shift で範囲、Cmd でトグル
- **縦ドラッグでスタックの並べ替え**（マウスアップでコミット。修飾キー付きの
  クリックは選択を作るだけで並べ替えない）
- 展開するとプロパティツリーが出る: プロパティグループ → チャネル行。
  チャネル行にはキーフレームのナビゲーションボタンが付く
- トグルの操作は**選択全体に適用**される（その行が選択に含まれるとき）

## レイヤーバー

| 領域 | 操作 |
|---|---|
| 本体 | ドラッグで `start_frame` を移動 |
| 左右の端（各 6px） | ドラッグで表示区間をトリム（in / out。`TRIM_HANDLE_PX`） |
| ロックされたレイヤー | 移動・トリムを受け付けない（現在は理由が画面に出ない → `PTR-3`） |

- 音声を持つレイヤーは準備中のあいだ「準備中」を表示する
- 波形表示は未実装（`AUDIO-5`）
- ドラッグは 1 ジェスチャ 1 undo

## キーフレーム

- チャネル行に菱形で表示する。ドラッグでレイヤーローカルのフレームを移動
- 空白のドラッグでラバーバンド選択（Shift で追加）
- 補間の切り替え: Bezier / Linear / Step（Action 経由）
- Delete で選択キーフレームを削除
- ラバーバンドが負のコンポジションフレームにある不可視キーを拾う不具合がある
  （`LOW-APP-04`）

## グラフモード（カーブエディタ）

- チャネルの値を時間軸に対して曲線で表示・編集する
- アンカーのドラッグでフレームと値を同時に変更、タンジェントのドラッグで
  ベジェハンドルを編集（既定は対称連動、**Alt で分離**）
- 空白のドラッグでラバーバンド選択
- ダブルクリックでキーフレームを追加
- `Channel4` が常に Color として描かれる不具合がある（`MED-APP-19`）

## 未実装項目

| 項目 | 担当 |
|---|---|
| 行の仮想化（レイヤー数に対する線形コスト） | `MED-UI-03`（フェーズ C3） |
| キャッシュ帯（AE の緑バー相当） | `CACHE-6` |
| カーブエディタの縦ズーム | `PARAM-5` |
| `Channel4` の型に応じた描画 | `MED-APP-19` |
| Vector の成分ラベルとリンクトグル | `MED-APP-20` / `VEC-5` |
| 音声波形の表示 | `AUDIO-5` |
| ポインタ形状のフィードバック（トリムエッジ / バー / キーフレーム） | `PTR-3` |
| マーカー、BPM グリッド、トランジション | 未計画（v1 仕様に図があったが Composition モデルでの設計が無い） |
| Dopesheet の独立パネル | 🔲 `PlaceholderPanel`。現状は Timeline 内のモード切替で代替 |
