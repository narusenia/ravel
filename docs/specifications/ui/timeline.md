# Timeline 仕様

> 最終更新: 2026-07-30 ／ 索引: [`../ui-spec.md`](../ui-spec.md)

アクティブコンポジションの時間ビュー。関連要件: REQ-UI-003、REQ-UI-012、
REQ-LAYER。

> **旧仕様との違い**: v1 の「Sequence ノードの糖衣 UI」「トラック / クリップ
> エディタ」「Timeline の二面性（Sequence 選択時は NLE、それ以外はドープシート）」は
> **実装されていない設計**。Timeline は常に `Composition` の `Layer` を並べ、
> ドープシートとカーブエディタはその**表示モード**として切り替わる。

## 構造

```text
┌──────────────────────────────────────────────────────────────┐
│ ▶ ■ │ 00:00:12:03 │ F │ [Dopesheet | Graph]                 │ ← トランスポート
├──────────────┬───────────────────────────────────────────────┤
│              │ |    |    |    |    |    |    |    |          │ ← ルーラー（フレーム / TC）
├──────────────┼───────────────────────────────────────────────┤
│ ▾ title  SML │        ▐████████████▌                         │ ← レイヤーバー
│   ▾ Transform│                                               │
│     Position │        ◆      ◆         ◆                     │ ← キーフレーム行
│ ▸ bg     SML │  ▐██████████████████████████▌                 │
└──────────────┴───────────────────────────────────────────────┘
   レイヤーヘッダー          レーン（1 枚の canvas 描画）
```

- 左のヘッダー列と右のレーンは横スクロールを共有しない（ヘッダーは固定幅）
- レーンは 1 枚の `canvas` に描く。行の仮想化は未実装（`MED-UI-03`）

## トランスポート

| 要素 | 内容 |
|---|---|
| 再生 / 一時停止 | `Space`。停止は `K` |
| フレーム送り / 戻し | `←` / `→` |
| タイムコード表示 | クリックで直接入力に切り替わる。Esc で取り消し |
| フォロー再生（`F` トグル） | 再生ヘッドが可視範囲外に出たらスクロールを追従させる |
| 表示モード切替 | ドープシート / グラフ（カーブエディタ） |
| BPM グリッド | `BPM` トグルとテンポ・1 拍目のフレーム（下の「BPM グリッド」節） |

再生位置のクロックは音声トラックがありデバイスが稼働中はオーディオ、
それ以外は wall clock。コンポジション終端では自動的に一時停止する。

## ルーラーとスクラブ

- ルーラー上の mousedown で再生ヘッドを移動し、**そのままドラッグを続けると
  ポインタがルーラーの外に出てもスクラブが続く**（`ScrubInput` と同じ契約）
- スクラブは Document を変更しないので undo に積まない
- 目盛りは minor / major の 2 段。フレームレートが minor ステップで割り切れない
  場合に major が描かれなくなる不具合がある（`LOW-APP-05`）

## コンポジション終端

Duration の外は**帯を敷いて落とす**。ルーラーとレーンの両方に敷き、終端の
フレームには 1px の線を引く。

- **ズームは終端で止めない。** 範囲外を見たい場面があるので、見えなくするの
  ではなく見分けが付くようにする
- グラフモード（カーブエディタ）には敷かない

## BPM グリッド

音楽に合わせる用途の拍グリッド。**フレームグリッドとは別物で、同時に出せる**。

| 項目 | 内容 |
|---|---|
| on / off | トランスポートの `BPM` トグル |
| テンポ | `BPM` の右の読み取り欄。クリックで直接入力（Enter で確定、Esc / blur で取り消し） |
| 1 拍目のフレーム | その右の `f` 付き読み取り欄。同じ操作 |
| 描く場所 | ルーラーとレーン（バー表示のとき）。グラフモードには描かない |

- 拍の位置は `offset + 拍番号 × (fps × 60 / BPM)`。**フレームに丸めない** —
  丸めるとフレームグリッドに吸い付き、数小節で 1 拍ぶんずれる。丸めが起きるの
  は描画のピクセル位置だけ
- 拍の間隔が 4px を切ったら描かない（線ではなく塗りつぶしになるため）
- テンポは 1〜999 BPM に丸め込む。0 や負の値は帯の計算が壊れる
- 状態は**コンポジションの属性ではなく UI 状態**で、`ui_state.json` に載る
  （絵に影響しないので `.ravprj` の `format_version` は上げない）。したがって
  **プロジェクトを保存したときに残り、保存せずに終了すれば残らない**

## ズームとスクロール

| 操作 | 割り当て |
|---|---|
| 水平ズーム | Cmd（または Ctrl）+ スクロール。ポインタ下のフレームを固定して拡大縮小 |
| 横スクロール | スクロールホイール |
| 縦スクロール | レーン領域の縦スクロール |

ズームのアンカーがウィンドウ空間で計算されている不具合がある（`HIGH-19`）。
カーブエディタの縦ズームは未実装（`PARAM-5` / `MED-APP-17`）。

## レイヤーヘッダー

- 名前、展開矢印、`S` / `M` / `L`（solo / mute / lock）のトグル
- 行のクリックでレイヤー選択。Shift で範囲、Cmd でトグル
- **縦ドラッグでスタックの並べ替え**（マウスアップでコミット。修飾キー付きの
  クリックは選択を作るだけで並べ替えない）
- 展開するとプロパティツリーが出る: プロパティグループ → チャネル行。
  チャネル行にはキーフレームのナビゲーションボタンが付く
- トグルの操作は**選択全体に適用**される（その行が選択に含まれるとき）

### プロパティ行

シェルのグループを AE の並びで出し、その後にキーフレームを持つネットワーク
パラメータが続く（`ravel_ui::keyframes::property_rows`）。

| 行 | 成分 | 出る条件 |
|---|---|---|
| アンカーポイント | `X` / `Y` | 常時 |
| 位置 | `X` / `Y` | 常時 |
| スケール | `X` / `Y` | 常時 |
| 回転 | 1 | 常時 |
| 不透明度 | 1 | 常時 |
| ゲイン | 1 | 音声を持つレイヤーのみ |
| ネットワークパラメータ | 1〜4 | いずれかの成分がキーフレームを持つとき |

### チャネル行の値スクラブ

チャネル行の右端に**その成分の現在値**を出し、そこを直接ドラッグして変える。
Properties へ往復せずに値を触るための経路。

- 挙動は Properties のスクラブと同じ（`widgets/scrub_input.rs`）。
  感度は UI レンジ由来、clamp は hard レンジ、Shift = 10x / Cmd = 0.1x、
  ドラッグせずに離すと数値入力になる
- **1 ジェスチャ 1 undo**。ドラッグ中の `Change` は undo を積まず、
  終端の `Commit` が 1 スナップショットを記録する
- 値は**再生ヘッドのレイヤーローカルフレーム**に書く。キーの打たれている
  チャネルはそのフレームのキーが更新され（無ければ挿入され）、定数の
  チャネルは定数が置き換わる（`ravel_ui::keyframes::set_channel_value`。
  Properties と同じ 1 本の書き込み経路）
- **単位は Properties と同じ**: スケールと不透明度はパーセント、他は生値。
  ネットワークパラメータは生値（レンジ情報はノード側にあり、行が持つ
  ノード id とキーからは引けない）。グラフモードの縦軸は生値のままなので、
  スケールと不透明度はグラフの目盛とこの表示がずれる
- **式・ブレンド・ノード出力に駆動された成分には値を出さない。**
  書き込み経路がその成分を拒むので、動かない操作子を置かない
- 値の押下はスクラブの開始であって、グラフ表示のチャネル選択ではない
  （行本体のクリックは従来どおり選択する）
- ドラッグ中は表示中のツリーが変わっても（絞り込み、undo、他パネルの編集）
  ウィジェットを捨てない。捨てると終端の `Commit` が届かず undo が 1 つ
  飛ぶ（`HIGH-28` と同型の欠陥）
- ウィジェットの同一性は**コンプ + レイヤー + 行 + 成分**。`LayerId` は
  コンプをまたいで再利用されるので、コンプを切り替えたときに前のコンプの
  ウィジェットが使い回されると、画面に出ていないコンプのレイヤーを書き換える
  （書き込み先はウィジェットを作った時点のコンプに固定されている）

### 行の絞り込み（AE の reveal）

キーで**行を絞り込む**。行の生成そのものは変わらず、フィルタが 1 枚かかる。

| chord | 出る行 |
|---|---|
| `U` | キーフレームを持つ行 |
| `A` / `P` / `S` / `R` / `T` / `L` | アンカーポイント / 位置 / スケール / 回転 / 不透明度 / ゲイン |
| `Alt+U` | 既定から変更済みの行 |
| `Alt+E` | 式に駆動されている行（ブレンド越しの式も含む） |

- **修飾なしは置換**、`Shift` 併用は現在の絞り込みに**足す**。同じキーを
  もう一度押すと全表示に戻る
- 絞り込みはパネルの状態なので、**レイヤーを選び直しても保たれる**
- 該当行の無いレイヤーはその行が空になるだけ（エラーにしない）
- AE の `E`（エフェクト）、`LL`（波形）、マスク各種は**入れない**。
  Ravel の効果はノードネットワークで行に対応する概念が無く（そのパラメータ行は
  `U` / `Alt+U` に含まれる）、波形は未実装（`AUDIO-5`）、マスクは無い
- 絞り込みは描画・ヒットテスト・ラバーバンド・高さ計算の**すべて**に効く
  （`TimelinePanel::visible_property_rows` の 1 経路。`MED-APP-13`）
- 展開は変えない。AE の `U` は選択レイヤーを開くが、ここでは開いている
  レイヤーのツリーを絞るだけ
- **`Alt+E` が拾えるのは行のある行だけ。** ネットワークのパラメータは
  キーフレームを持って初めて行になる（`property_rows`）ので、**一度も
  キーフレームを打たずに式だけ付けたパラメータには絞り込む行が無い**。
  行の生成を広げるのはこのフィルタの仕事ではない — 絞り込み中だけでなく
  全員のツリーが変わってしまう
- 「式を持つ」の判定は Properties の式バッジと**同じ 1 つの定義**
  （`properties::expression::source_has_expression`）。ブレンドの中の式を
  片方のパネルだけが駆動と見なす、という食い違いを作らない

## レイヤーバー

| 領域 | 操作 |
|---|---|
| 本体 | ドラッグで `start_frame` を移動 |
| 左右の端（各 6px） | ドラッグで表示区間をトリム（in / out。`TRIM_HANDLE_PX`） |
| ロックされたレイヤー | 移動・トリムを受け付けず、`OperationNotAllowed` カーソルで示す |

- 音声を持つレイヤーは準備中のあいだ「準備中」を表示する
- 波形表示は未実装（`AUDIO-5`）
- ドラッグは 1 ジェスチャ 1 undo
- **移動もトリムも選択全体に適用される**（掴んだバーが選択に含まれるとき。
  トグル・削除・複写と同じ規約）。トリムの制限は**レイヤーごとに自分の
  表示区間**で掛かるので、短いレイヤーが止まっても他は動き続ける。
  ロックされたレイヤーは対象から外れる
- **選択済みのバーを修飾なしで押しても選択は保たれる**（掴んだ集合を
  そのまま動かすため）。動かさずに離したときだけ、そのバー 1 枚に絞る。
  ジェスチャが始まらない押下（ロックされたレイヤー、バーを外した押下）は
  普通のクリックなので、その場で 1 枚に絞る

## キーフレーム

- チャネル行に菱形で表示する。ドラッグでレイヤーローカルのフレームを移動
- 空白のドラッグでラバーバンド選択（Shift で追加）
- 補間の切り替え: Bezier / Linear / Step（Action 経由）
- Delete で選択キーフレームを削除
- ラバーバンドが負のコンポジションフレームにある不可視キーを拾う不具合がある
  （`LOW-APP-04`）

## グラフモード（カーブエディタ）

- チャネルの値を時間軸に対して曲線で表示・編集する
- アンカーのドラッグでフレームと値を同時に変更、タンジェントのドラッグで
  ベジェハンドルを編集（既定は対称連動、**Alt で分離**）
- 空白のドラッグでラバーバンド選択
- ダブルクリックでキーフレームを追加
- `Channel4` が常に Color として描かれる不具合がある（`MED-APP-19`）

## 翻訳しない表記

Timeline の一部の文字は**言語に依存しない記法**として、ロケールカタログを
通さずそのまま描く。意味は必ず別の要素（ツールチップ、行ラベル、
プロパティ行）がローカライズされた語で伝える。

| 表記 | 意味 | ローカライズされた対 |
|---|---|---|
| `f` | フレーム数の単位（`120f`、`300f`） | Properties の Duration 行（`properties.value.duration_frames`） |
| `fps` | frames per second | Composition 設定のフレームレート欄 |
| `S` / `M` / `L` | solo / mute / lock のトグル | `timeline.toggle.solo` / `.mute` / `.lock` のツールチップ |
| `F` | フォロー再生のトグル | `timeline.toggle.follow_playhead` のツールチップ |
| `BPM` | 拍グリッドのトグル | `timeline.bpm.toggle` のツールチップ |
| `X` / `Y` | 成分チャネルの軸 | 親のプロパティ行（`timeline.property.position` など） |
| `R` / `G` / `B` / `A` | カラーチャネルの成分 | 親のプロパティ行（ノード名 · パラメータ名） |

語で名づけられる成分（回転、不透明度、ゲイン、単一チャネルの「値」）は
記法ではないのでロケールキーで持つ（`timeline.property.*` と
`timeline.channel.value`）。`ravel-ui` は i18n に依存しないため、
`PropertyRow::channel_names` はキーと記法が混ざった配列で、
`ravel-app` の `channel_name_label` が表示境界で解決する
（カタログに無い文字列はそのまま通るので、記法は素通りする）。
