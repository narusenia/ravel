# Viewer 仕様

> 最終更新: 2026-08-15 ／ 索引: [`../ui-spec.md`](../ui-spec.md)

アクティブコンポジションの出力を表示し、その上で直接編集する。
関連要件: REQ-UI-004、REQ-UI-011、REQ-LAYER-007。

## 表示するもの

- **常にアクティブコンポジションの root 出力**を表示する。選択ノードの単独
  プレビューは採らない（ユーザー判断で削除済み）
- 評価はバックグラウンドワーカーで行い、結果は `ViewerFrame` Global 経由で届く。
  latest-wins でスクラブ中の中間フレームを間引く
- **表示用の変換（f32 RGBA → BGRA u8）もそのワーカーで行う**。UI スレッドは
  出来上がった画像を持つだけで、フレームごとのピクセルループを持たない
- フレーム位置は共有の再生ヘッドに従う。音声トラックがありデバイスが稼働中は
  オーディオクロックが再生位置の正、それ以外は wall clock
- 評価が失敗したときは stale なフレームを破棄し、黒フレームの上に小さく
  エラーを重ねる
- コンポジション解像度と評価バッファの解像度は別に扱う（バッファが小さくても
  オーバーレイはコンプ座標で正しく描く）

`Composition.background_color` は合成チェーン最下段の `comp.background` で
評価結果へ含まれる。アルファは保持され、レイヤーが無い領域にも同じ結果が出る。
Viewer の背景表示はセッション内でコンプ背景 / スクリーン空間固定サイズの
チェッカーボード / 黒単色を切り替えられる。

## ビューポート操作

| 操作 | 割り当て |
|---|---|
| ズーム | スクロールホイール（**修飾キー無し**）。ポインタ位置を中心に拡大縮小 |
| パン | 中ボタンドラッグ（**どのツール中でも有効**） |
| フィット | ツールバーのボタン。ズーム率は数値表示から直接指定できる |
| プレビュー解像度 | ツールバーのセレクト（フル / 1/2 / 1/4）と `View ▸ プレビュー解像度を切り替え`（`Alt+R`、循環）。既定は 1/2。**表示倍率ではなく評価倍率**で、コンプ解像度に係数を掛けた解像度で評価する（REQ-UI-004、`done/viewer-preview-resolution-plan.md`）。**操作中（ドラッグ・スクラブ・パラメータ編集）は自動で 1 段下がり**、最後の入力から 120 ms で選択した係数へ戻って 1 回だけ再評価する（`Quarter` は下がらない。再生中は下げない）。下がっている間は選択中の係数と実効係数を並べて出す |

MediaBin から画面へドロップすると、**再生ヘッド位置**にレイヤーとして置かれる
（Viewer が映すのは 1 瞬間なので、ドロップ位置は時間を指さない）。

Hand ツールによる左ドラッグパンと Zoom ツールのクリックズームは**未実装**。
担当は `viewer-tool-extensions-plan.md` の `TOOLX-1`（issue は `MED-APP-15`）。

## ツール

ツール状態は durable Global（`ToolState`）。切り替えは `CommandId` + Action で、
ショートカットは Viewer のキーコンテキストに束縛される。

| ツール | キー | 状態 |
|---|---|---|
| 選択 / 移動 | `V` | ✅ |
| ペン | `P` | ✅ |
| 矩形描画 | `R` | ✅ |
| 楕円描画 | `E` | ✅ |
| ハンド | `H` | 🔲 切り替わるが動作しない（`TOOLX-1`） |
| ズーム | `Z` | 🔲 同上 |

- ショートカットは `workspace.rs` にハードコードされており、
  `assets/keybindings/default.toml` には**含まれない**。ユーザー上書きの対象外
- `H` はタップで切り替え、**ホールドで一時ハンド**（離すと元のツールに戻る）。
  Space を一時ハンドに使わないのは再生 / 停止と衝突するため
- ツールバーは Viewer 内上部のストリップ。現在のツールが選択状態で示される

## 選択

- ヒット対象は**アクティブレイヤー（Node Editor が開いているネットワーク）内の
  geometry ノード**。評価済みジオメトリの AABB 近似で判定する
- Shift + クリックでトグル追加。空白クリックで解除
- 選択の正は `CanvasSelection`（ネットワーク + ノード集合）。Node Editor と
  Properties は同じ Global を読むので、Viewer で選ぶと両方が追従する
- レイヤーが 2 つ以上選択されているときはネットワークが開かないので、
  Viewer の選択はレイヤー単位として振る舞う

未実装: 矩形選択（`TOOLX-2`）、アクティブレイヤー外へのフォールバック
（`TOOLX-3`）、ピクセル精度のヒットテスト（REQ-UI-011 の v2）。

## バウンディングボックスとハンドル

- 選択ノードの評価済み bounds を表示する。複数選択は合成 AABB + 個別の薄い枠。
  表示にはレイヤー殻の変換を順方向に適用する。
- レイヤー単位の選択（2 枚以上）では、そのネットワークの shape ノードの
  bounds の和を殻変換して描く。shape ノードを持たないレイヤーは bbox を描かない。
- ノード選択の bbox に見える 8 個の印は飾りである。殻の編集は `ShellManipulator`
  が同じ位置に出す自前の印で行い、ノード bbox の印自体は値を書き換えない。
- `Select` ツールでジオメトリを持つレイヤーを 1 枚だけ選んだとき、殻の 8 個の
  スケールハンドル、回転リング、中央の移動グリップ、アンカーマーカーを表示する。
  キーフレーム付きチャネルは現在のレイヤーのローカルフレームへ書き、親チェーンの
  行列を含む座標で表示・編集する。

## 編集

### ノード編集

bbox の内側からのドラッグで移動する。動かせるのは**位置を自身のパラメータに
持つノード**だけ:

- `center` 系パラメータを持つノード（shape 系 / scatter 系）
- `PathPoints` を持つノード（全制御点を一括オフセット。接線は相対なので保持）
- 直下流に `geometry.transform` があるノード（その translate を書く）

ツールによる暗黙のノード自動挿入は行わない（ノードグラフが正という原則）。
ドラッグ中は bbox をローカル予測で即時追従させ、ジオメトリ本体は背景評価に従う。
**1 ドラッグ = 1 undo**、Esc で revert。複数選択は移動可能なノード全部へ同一デルタ。

殻変換が単位行列でないレイヤーは**読み取り専用**（表示は常に正しく、編集可能
条件は明確に）。見た目座標での逆変換編集は REQ-UI-011 の v2。

ノード bbox の内側ドラッグはノード選択・移動の経路として残すが、殻の移動用に
bbox 全面を `OverlayHandle` へ載せ替えない。全面をハンドルにするとレイヤー内
ノードのクリック選択を奪うため、殻の移動は中央グリップから始める。

### レイヤー殻とパラメータのマニピュレータ

- 殻の角・辺ハンドルはスケール、回転リングは回転、中央グリップは移動、アンカー
  マーカーは `anchor_point` と `position` の同時編集を行う。アンカー移動では見た目
  のワールド位置を維持する。
- `Shift` はスケールの縦横比固定だけに効き、`Alt` はアンカー基準にする。回転の
  角度スナップと移動の軸拘束は提供しない。ドラッグ HUD はキャンバス左上に固定する。
- `ParamRole` は `Position` / `Size` のみ。対応するノードの評価済みジオメトリに
  ハンドルを出し、アニメーション付きの値は現在のローカルフレームへ書く。
  `Direction` / `Angle` は未導入で、接続で駆動されるパラメータにはハンドルを出さない。
- いずれのドラッグも live apply と mouse-up commit の既存経路を使い、1 ジェスチャ
  を 1 undo にまとめる。`Escape` は押下時のスナップショットへ戻す。ドラッグ中に
  選択が変わった場合も同じスナップショットへ戻して打ち切る。

### シェイプ描画

ドラッグ矩形から `shape.rect` / `shape.ellipse` を生成する。中心 → center、
寸法 → size、Shift で正形、Alt で中心から描画。生成先はアクティブレイヤーの
ネットワークで、既存 rasterize の geometry 入力が空いていれば自動接続する
（埋まっていれば未配線で置く。merge の自動挿入はしない）。レイヤーが無ければ
Shape レイヤーテンプレートを作る。

polygon / star はドラッグ 1 回でパラメータが決まらないため未実装（`TOOLX-4`）。

### ペン

- クリックでコーナー点、ドラッグでスムーズ点（対称接線）、始点クリックで閉路、
  Esc で確定
- 点列は `ParameterValue::PathPoints`（`p` / `in_tan` / `out_tan`）として
  `shape.custom_path` のパラメータに保存する。undo・RON 永続化・Properties は
  既存経路に乗る
- 既存点とハンドルの移動は可能
- 曲線はコンプ空間固定 tolerance の共有フラット化で描く（CPU と GPU に同一の
  折れ線を渡し、等価性テストを維持する）

未実装: 点の挿入 / 削除、Alt によるハンドル分離（どちらも `TOOLX-3`）。
パスアニメーション（点列の時間変化）は設計メモのみ
（`docs/implementation/path-channel-design.md`）。

## 吸着（スナップ）

レイヤー移動、シェイプ描画、殻のグリップのドラッグは、閾値内の候補へ吸着する。

- 候補は**コンプ枠の端と中心**、**セーフエリア**（表示中のみ）、
  **ユーザーガイド**（表示中のみ）、**動かしていないレイヤーの bbox の端と
  中心**。動かしているレイヤーとドラッグ中のガイド自身は候補から外す
  （矩形は自分自身から常に距離 0 なので、残すと開始位置に貼り付く）
- 判定は**スクリーン距離 8px** で、コンプ空間へ逆変換して比較する。
  ズームを変えても画面上の効き幅は変わらない
- 同距離の候補が複数あるときは列挙順で先のものを採る
  （コンプ枠 → セーフエリア → ガイド → レイヤー）。同じ入力に対して
  毎回同じ候補を選ぶ
- 吸着が成立した軸に、そのフレームだけマゼンタのガイド線を描く。
  ジェスチャーが終われば消える
- **Cmd / Ctrl 押下中は吸着しない**。Alt ではない（Alt は中心描画と
  アンカー基準スケールに割り当て済み）
- **Shift が拘束として効くジェスチャー（シェイプ描画・殻のスケール）では
  吸着しない**。拘束が吸着後の座標を上書きし、ガイド線が実際の端点と
  違う場所を指すため。Shift が何もしないジェスチャーでは吸着を続ける
- 編集しない軸には補正もガイド線も出さない（殻の片軸グリップ、ガイドの
  ドラッグ）。出すと動かない軸の整列を約束し、no-op の undo を積む

## 定規とユーザーガイド

- 定規はキャンバスの上端と左端に置く **16px の帯**で、ツールバーのメニューから
  表示を切り替える（既定は非表示）。目盛りの刻みは 1-2-5 系列から選び、画面上の
  間隔が 6px 以上 15px 未満に収まるようズームに追従する。5 本ごとに帯いっぱいの
  長い目盛りを描く。**数値ラベルは無い**
- 上の定規からのドラッグで**横ガイド**、左の定規からのドラッグで**縦ガイド**を
  作る。ガイドは押下時にドキュメントへ入り、離した時点で **1 操作 1 undo** として
  確定する
- 既存ガイドは線から **6px 以内**の押下で掴んで動かす。**定規の帯の上で離すと
  削除**。ツールバーのメニューに「ガイドを消去」もある。`Escape` は押下時の
  スナップショットへ戻し、動かさずに離した場合は何もコミットしない
- ガイドは `Composition.guides`（縦 / 横 + コンプ空間の位置）が持つ。undo /
  redo・保存・再読込は既存経路に乗り、**`.ravprj` の format version は
  上げていない**（`#[serde(default)]` の追加フィールド）
- **表示 / 非表示とロックはセッション状態**で、グリッドやセーフエリアのトグルと
  同じ扱い。プロジェクトには保存しない
- **非表示のガイドは描かれず、吸着候補にもならない**。**ロック中のガイドは
  描かれ吸着候補にも残る**が、作成・移動・削除ができない（ロックは「動かさない」
  であって「無視する」ではない）
- 定規とガイドの操作は **Select ツール限定**。他のツールの押下は奪わない

## オーバーレイ機構

Viewer の重ね描きは `ViewerOverlay` を実装単位とし、`OverlayRegistry` が描画順と
ヒットテストの優先度を管理する。各オーバーレイは `OverlayContext` から選択・
ツール・評価結果を読み、`OverlayPainter` の composition-space / screen-space API
で描画する。固定 px のハンドルやルールは screen space、ジオメトリは composition
space とする。

ハンドルを持つオーバーレイは `handles` と `drag` を同じ実装に置く。描いた印と
掴める位置は同じ resolved data から作り、編集は `OverlayEdit` を Document の
live apply / mouse-up commit 経路へ渡す。`eval_targets` に対応する評価結果がまだ
無い場合は何も描かず、値を推測しない。描画ツールが入力を所有する条件では
`is_active` を false にし、専用の canvas 分岐で入力を奪わない。

現在の組み込みオーバーレイは次のとおり。

| オーバーレイ | 内容と表示条件 |
|---|---|
| 比率グリッド / セーフエリア | コンプ枠の分割線と安全領域の枠。ツールバーの表示トグルで切替 |
| Geometry | 選択ジオメトリの bbox / points / instances / paths、属性の矢印・インデックス・グループ。矢印は実際の `Vec2` / `Vec3` / `Vec4` 属性から作り、ラベルは最大 64 件。矢印長の上限はコンプ座標の短辺 15% |
| Field | 選択した field ノードの heatmap / 等値線 / ベクトル矢印。等値線は marching squares ではなくセル解像度の階段。表示モード、カラーマップ、opacity を切替可能 |
| Path | アンカーと接線。スクリーン空間の固定サイズで描く |
| ShellManipulator | Select ツールでジオメトリを持つレイヤーを 1 枚選んだときのスケール、回転、中央移動、アンカー、親子リンク線、固定 HUD |
| ParamManipulator | `ParamRole::Position` / `Size` に対応するノードのハンドル。接続で駆動される値には出さない |
| MotionPath | Select ツールでレイヤーを 1 枚選び、`position` に 2 個以上のキーがあるときの折れ線とキー点。トグルは無い |
| ガイド | `Composition.guides` の線。ツールバーのメニューで表示を切り替える |
| 吸着ガイド | ドラッグ中に吸着が成立した軸の線。ジェスチャー中だけ描く |
| 評価エラー | 評価失敗時の診断メッセージ |

Geometry と Field の表示項目には Viewer ツールバーの locale 済みトグルがある。
MotionPath と吸着ガイドはトグルではなく条件付きで有効になる。モーションパスの
キー点ドラッグはそのローカルキーフレームの位置成分を書き換えるが、空間 Bezier は
持たない。

**定規だけはオーバーレイではない。** `OverlayPainter` が知るのはコンプ矩形だけで、
ズームインすると矩形はパネルから出てしまう。定規はパネルの縁に貼り付く必要が
あるので、チェッカーボードと同じ `(panel, frame)` の組からキャンバスの描画
クロージャで描く。同じ理由で、定規の帯とガイド線の掴みは `OverlayHandle` では
なくパネル側の押下分岐が受ける（帯はコンプ矩形の外にあり、ガイドは線なので
registry の「点からの半径」ヒットテストで表現できない）。`Select` ツール限定
という条件で、描画ツールの押下は奪わない。
