# Viewer 仕様

> 最終更新: 2026-08-05 ／ 索引: [`../ui-spec.md`](../ui-spec.md)

アクティブコンポジションの出力を表示し、その上で直接編集する。
関連要件: REQ-UI-004、REQ-UI-011、REQ-LAYER-007。

## 表示するもの

- **常にアクティブコンポジションの root 出力**を表示する。選択ノードの単独
  プレビューは採らない（ユーザー判断で削除済み）
- 評価はバックグラウンドワーカーで行い、結果は `ViewerFrame` Global 経由で届く。
  latest-wins でスクラブ中の中間フレームを間引く
- **表示用の変換（f32 RGBA → BGRA u8）もそのワーカーで行う**。UI スレッドは
  出来上がった画像を持つだけで、フレームごとのピクセルループを持たない
- フレーム位置は共有の再生ヘッドに従う。音声トラックがありデバイスが稼働中は
  オーディオクロックが再生位置の正、それ以外は wall clock
- 評価が失敗したときは stale なフレームを破棄し、黒フレームの上に小さく
  エラーを重ねる
- コンポジション解像度と評価バッファの解像度は別に扱う（バッファが小さくても
  オーバーレイはコンプ座標で正しく描く）

`Composition.background_color` は合成チェーン最下段の `comp.background` で
評価結果へ含まれる。アルファは保持され、レイヤーが無い領域にも同じ結果が出る。
Viewer の背景表示はセッション内でコンプ背景 / スクリーン空間固定サイズの
チェッカーボード / 黒単色を切り替えられる。

## ビューポート操作

| 操作 | 割り当て |
|---|---|
| ズーム | スクロールホイール（**修飾キー無し**）。ポインタ位置を中心に拡大縮小 |
| パン | 中ボタンドラッグ（**どのツール中でも有効**） |
| フィット | ツールバーのボタン。ズーム率は数値表示から直接指定できる |

MediaBin から画面へドロップすると、**再生ヘッド位置**にレイヤーとして置かれる
（Viewer が映すのは 1 瞬間なので、ドロップ位置は時間を指さない）。

Hand ツールによる左ドラッグパンと Zoom ツールのクリックズームは**未実装**。
担当は `viewer-tool-extensions-plan.md` の `TOOLX-1`（issue は `MED-APP-15`）。

## ツール

ツール状態は durable Global（`ToolState`）。切り替えは `CommandId` + Action で、
ショートカットは Viewer のキーコンテキストに束縛される。

| ツール | キー | 状態 |
|---|---|---|
| 選択 / 移動 | `V` | ✅ |
| ペン | `P` | ✅ |
| 矩形描画 | `R` | ✅ |
| 楕円描画 | `E` | ✅ |
| ハンド | `H` | 🔲 切り替わるが動作しない（`TOOLX-1`） |
| ズーム | `Z` | 🔲 同上 |

- ショートカットは `workspace.rs` にハードコードされており、
  `assets/keybindings/default.toml` には**含まれない**。ユーザー上書きの対象外
- `H` はタップで切り替え、**ホールドで一時ハンド**（離すと元のツールに戻る）。
  Space を一時ハンドに使わないのは再生 / 停止と衝突するため
- ツールバーは Viewer 内上部のストリップ。現在のツールが選択状態で示される

## 選択

- ヒット対象は**アクティブレイヤー（Node Editor が開いているネットワーク）内の
  geometry ノード**。評価済みジオメトリの AABB 近似で判定する
- Shift + クリックでトグル追加。空白クリックで解除
- 選択の正は `CanvasSelection`（ネットワーク + ノード集合）。Node Editor と
  Properties は同じ Global を読むので、Viewer で選ぶと両方が追従する
- レイヤーが 2 つ以上選択されているときはネットワークが開かないので、
  Viewer の選択はレイヤー単位として振る舞う

未実装: 矩形選択（`TOOLX-2`）、アクティブレイヤー外へのフォールバック
（`TOOLX-3`）、ピクセル精度のヒットテスト（REQ-UI-011 の v2）。

## バウンディングボックスとハンドル

- 選択ノードの評価済み bounds を表示する。複数選択は合成 AABB + 個別の薄い枠
- 表示にはレイヤー殻の変換を順方向に適用する（見た目と常に一致させる）
- レイヤー単位の選択（2 枚以上）では、そのネットワークの shape ノードの
  bounds の和を殻変換して描く。shape ノードを持たないレイヤーは描かない
- **8 個のハンドルは現状「飾り」** — スケールも回転もジェスチャーが存在しない。
  動作を与えるのは `viewer-overlay-manipulator-plan.md` の `OVL-7`

## 編集

### 移動

bbox の内側からのドラッグで移動する。動かせるのは**位置を自身のパラメータに
持つノード**だけ:

- `center` 系パラメータを持つノード（shape 系 / scatter 系）
- `PathPoints` を持つノード（全制御点を一括オフセット。接線は相対なので保持）
- 直下流に `geometry.transform` があるノード（その translate を書く）

ツールによる暗黙のノード自動挿入は行わない（ノードグラフが正という原則）。
ドラッグ中は bbox をローカル予測で即時追従させ、ジオメトリ本体は背景評価に従う。
**1 ドラッグ = 1 undo**、Esc で revert。複数選択は移動可能なノード全部へ同一デルタ。

殻変換が単位行列でないレイヤーは**読み取り専用**（表示は常に正しく、編集可能
条件は明確に）。見た目座標での逆変換編集は REQ-UI-011 の v2。

### シェイプ描画

ドラッグ矩形から `shape.rect` / `shape.ellipse` を生成する。中心 → center、
寸法 → size、Shift で正形、Alt で中心から描画。生成先はアクティブレイヤーの
ネットワークで、既存 rasterize の geometry 入力が空いていれば自動接続する
（埋まっていれば未配線で置く。merge の自動挿入はしない）。レイヤーが無ければ
Shape レイヤーテンプレートを作る。

polygon / star はドラッグ 1 回でパラメータが決まらないため未実装（`TOOLX-4`）。

### ペン

- クリックでコーナー点、ドラッグでスムーズ点（対称接線）、始点クリックで閉路、
  Esc で確定
- 点列は `ParameterValue::PathPoints`（`p` / `in_tan` / `out_tan`）として
  `shape.custom_path` のパラメータに保存する。undo・RON 永続化・Properties は
  既存経路に乗る
- 既存点とハンドルの移動は可能
- 曲線はコンプ空間固定 tolerance の共有フラット化で描く（CPU と GPU に同一の
  折れ線を渡し、等価性テストを維持する）

未実装: 点の挿入 / 削除、Alt によるハンドル分離（どちらも `TOOLX-3`）。
パスアニメーション（点列の時間変化）は設計メモのみ
（`docs/implementation/path-channel-design.md`）。

## オーバーレイ

現在 5 種を重ねている。

| オーバーレイ | 内容 |
|---|---|
| 比率グリッド | コンプ枠の分割線 |
| セーフエリア | 安全領域の枠 |
| 選択 bbox | 上記「バウンディングボックス」 |
| パス編集ハンドル | アンカーと接線。**スクリーン空間の固定サイズ**で描く（ズームで大きさが変わらない） |
| 評価エラー | 失敗時のメッセージ |

これらは Viewer の paint クロージャに直書きされている。拡張可能な機構への
載せ替えは `viewer-overlay-manipulator-plan.md` の `OVL-1`（挙動不変）。
以降のオーバーレイはすべてその機構を通す:

- Field / Geometry の可視化、属性の矢印とラベル（`OVL-3` / `OVL-4` / `OVL-8`）
- 殻トランスフォームのマニピュレータとドラッグ HUD、親子リンク線（`OVL-7`）
- モーションパス（`OVL-9`）
- パラメータマニピュレータ（`OVL-5`）
- 吸着ガイドと定規・ユーザーガイド（`SNAP-1` / `SNAP-2`）
